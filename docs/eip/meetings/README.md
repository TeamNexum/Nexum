# Suivis et réunions : le process

Deux types de rendez-vous rythment l'EIP. Chacun a ses règles, à suivre à chaque fois.
Ticket de suivi : #46.

## Suivi pédagogique (référent Epitech)

Avant :
- Préparer une démo du travail fait depuis le dernier point : l'avancement doit être visible.

Pendant :
- Caméra allumée (obligatoire).
- Tour de table et démo, puis point d'équipe : ambiance, motivation, problèmes.
- Fixer la date du prochain suivi avant de raccrocher.

Après (dans les 48 h) :
- Publier le compte rendu ici, avec le modèle [`_MODELE_compte-rendu.md`](_MODELE_compte-rendu.md).
- Transformer chaque décision en ticket GitHub (ou mettre à jour le ticket existant).

## Session de mentorat (mentor de la track)

Avant, **règle du mentor : envoyer le compte rendu à Pitek 48 à 72 h avant la séance**
(rappelée au suivi du 19/10) :
- Remplir [`_MODELE_avant-mentor.md`](_MODELE_avant-mentor.md) : avancement, chiffres, décisions à
  prendre, questions pour le mentor.
- L'envoyer à Pitek, puis cocher l'envoi sur le ticket de la séance (ex. #120).

Pendant :
- Revue de la stratégie de la track (Entrepreneuriat, objectifs B et C).
- Résoudre ensemble les points bloquants.
- Repartir avec des prochaines étapes claires et un responsable pour chacune.

Après (dans les 48 h) :
- Publier le compte rendu ici avec [`_MODELE_compte-rendu.md`](_MODELE_compte-rendu.md).
- Créer les tickets (responsable, date cible, priorité) et mettre à jour le board.
- Ajouter la date de la séance suivante au calendrier de l'équipe.

## Nommage

`AAAA-MM-JJ-type.md`, par exemple `2026-10-19-suivi-mentor.md` ou `2026-09-25-suivi-pedagogique.md`.
